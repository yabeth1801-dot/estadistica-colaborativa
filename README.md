# Proyecto de Estadística Colaborativa

Proyecto en Python para practicar Git y GitHub de manera colaborativa.

## Objetivos

- Generar datos.
- Realizar análisis estadístico.
- Crear visualizaciones.
- Practicar ramas y commits.
- Practicar push, pull, fetch, clone y merge.
- Utilizar Pull Requests.

## Tecnologías

- Python
- NumPy
- Matplotlib
- Git
- GitHub
